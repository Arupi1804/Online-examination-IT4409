# Shared package

Chứa type, Zod schema và event constants dùng chung cho client/server.

Import qua `@online-exam/shared`. `src/index.ts` export quy ước từ PDF; build JavaScript và declaration ra `dist`. Root `pnpm dev` build trước rồi watch shared. Không import trực tiếp source xuyên package. Thay đổi contract cần TV1 và người bị ảnh hưởng duyệt.
